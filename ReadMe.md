# Adapting Decentralized Finance Market Principles to Peer-to-Peer Energy Markets

This repository contains the code and resources for the Master Thesis titled "Adapting Decentralized Finance Market Principles to Peer-to-Peer Energy Markets". The project simulates two local energy market approaches across three scenarios of prosumer participation.

## Getting Started

### Prerequisites

- Node.js
- Ganache
- Truffle

### Installation

1. Clone the repository:
    ```bash
    git clone <repository-url>
    ```
    ```
2. Install the required packages:
    ```bash
    npm install
    ```

### Running the Simulation

1. Start Ganache blockchain instance:
    ```bash
    npm run ganache
    ```
2. In a new terminal, migrate the contracts using Truffle:
    ```bash
    truffle migrate
    ```
3. Open the `AMMBA_simulation.ipynb` notebook and start the simulation. Ensure that the correct contract addresses are set in the notebook.
